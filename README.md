# Pendi

A calm, mobile-first daily planner: reading, competitive programming, work, and college in one Today screen. Flutter + Supabase.

```
flutter pub get
flutter run            # demo mode: no backend needed
```

Copy `env.example.json` to `env.json`, fill it in, and run with `--dart-define-from-file=env.json` to use Supabase and Google.
